## 原书疑点

1. 第 47 页 SRT 规则「if r ≥ 1/4 and subtract b from 2r」语法不完整（应为 then subtract），按意思译为「如果 r ≥ 1/4，就从 2r 中减去 b」。
2. 第 50 页图 J.26 说明「Low-order bits of A are 1, 0; L = 0, so add −2b」，而图 J.25 中 (1,0,0) 对应 −2b，一致；P 一列加的 01010 是 −2b（b = 1011 即 −5）的补码，照录。
3. 第 46 页 SRT 步骤 2「For i = 0, n − 1」照录。
4. 第 45 页「See Exercise J.26」，本附录习题尚未定锚点，写成纯文本「习题 J.26」。
