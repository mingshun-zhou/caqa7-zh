# 第 1 章校对记录：1.7–1.9 节（PDF 第 42–57 页）

## 疑似原书问题

- 1.9 节正文 “Figure 1.20 lists the 17 SPEC benchmarks that are active in 2023”，图 1.20 图注却是 “as of 2022”；而且表中实际列出 20 项（云 1、CPU 1、图形和工作站 6、高性能计算 4、Java 4、功耗 1、存储 1、虚拟化 2），与「17 个」不符。照原文译。
- 图 1.20 “SPECapcSM for Maya® 2017” 一行的说明写的是 “Autodesk 3ds Max 2017 app”，名称与说明不一致，疑原书错；照原文译。
- 图 1.20 功耗一行 “ACCEL, CPU 2017, OMP, 2012, and VIRT_SC 2013”，“OMP, 2012” 中间多一个逗号，疑应为 OMP 2012；照原文保留。
- 图 1.20 原书表格的行序：高性能计算一栏原排在图形栏后面，SPEC MPI 2007、SPEC OMP 2012、SPECapcSM for PTC Creo 3.0 在 pdftotext 里散落在表尾；按页面图的实际排列整理。
- 图 1.19 图注：SPEC2017 浮点程序按语言为 3+2+2+6=13 个，与正文 “17 floating-point benchmarks” 不符（可能是 speed/rate 口径不同），照原文译。
- 图 1.21 图注 “the ratio of the geometric means (11.69/11.99 = 0.98)”：11.69 是 Intel、11.99 是 AMD，所以这是 Intel/AMD；对应最后一列。另外倒数第二列表头写 “AMD/Intel times (seconds)”，比值本无单位，照原文保留「（秒）」。
- 1.9 节 “suppose that the SPECRatio of computer A on a benchmark is 1.25 times as fast as computer B”：原文把 SPECRatio 说成 “as fast as”，表述不严谨，译为「A 的 SPECRatio 是 B 的 1.25 倍」。
- 1.9 节 “The goal is to try to reduce the effect of ‘benchmarketing’ (see Section 1.11)” 句末原书缺句号，不影响翻译。
- 1.7 节 “One suggests improving postmanufacturing testing”：One 指哪位研究者原文未说，译为「有一位研究者建议」。
- 1.7 节冗余电源例题 MTTF 公式中，原书第一个等号右边是繁分式，按页面图排成 \dfrac 嵌套。

## 新定术语

- dependability 可信性；reliability 可靠性；availability 可用性
- transient / permanent fault（error） 瞬时故障（错误）/ 永久故障（错误）；fault 故障，failure 失效，error 错误
- mercurial core 反复无常的核
- silent data error 静默数据错误；silent corrupt execution error 静默错误执行
- service-level agreement（SLA）服务等级协议；service-level objective（SLO）服务等级目标
- service accomplishment / interruption 服务完成 / 服务中断；restoration 恢复
- MTTF 平均无故障时间；MTTR 平均修复时间；MTBF 平均故障间隔时间；AFR 年失效率；FIT 保留英文
- 公式下标：system 系统，power supply 电源，power supply pair 电源对
- row hammer 行锤击；hammering 锤击；victim row 受害行；disturbance error 干扰错误
- timing channel 时序信道；side channel 侧信道；speculation 推测；“breadcrumbs” 面包屑
- hypervisor 虚拟机管理程序；Dedicated Instances 专用实例
- response time 响应时间；execution time 执行时间；wall-clock time 墙钟时间；elapsed time 经过时间；CPU time CPU 时间；workload 工作负载
- benchmark 基准测试程序；benchmark suite 基准测试程序集；kernel 核心程序；toy program 玩具程序；synthetic benchmark 合成基准测试程序；benchmarketing 基准营销
- base / peak 保留英文，首次注「基础 / 峰值」
- SPEC 标准性能评估公司；TPC 事务处理委员会；TP 事务处理；OLTP 联机事务处理；ad hoc 即席；data integration 数据集成
- reproducibility 可重现；SPECRatio 保留英文；geometric mean 几何平均
- 图 1.19 图内英文标注未译。

## 润色时的改动

- 术语统一：1.7 节 failure rate 由「失效率」改为「故障率」（含 AFR「年故障率」及两道例题公式里的 \text{失效率} 标签），与 miss rate「失效率」区分；failure 本身仍译「失效」。上面「新定术语」里的「AFR 年失效率」以此为准。
- 1.9 节 “Attempts at running programs that are much simpler than a real application have led to performance pitfalls”：第一稿译成假设句「如果改用……就会掉进……陷阱」，把已经发生的事实说成了条件推断；改为「尝试运行比真实应用简单得多的程序，已经带来了不少性能评测上的陷阱」。
- 1.9 节 “a distaste of the inaccuracy”：第一稿「人们厌恶……不准确」语气偏重，改为「人们不满于……不够准确」。
- 1.9 节 “the ratio of the geometric means … is the geometric mean of the performance ratios” 前的 “Notice that the execution times on the reference computer drop out”：「被约掉了」改为「相互约去」，意思不变。
- 去掉常见术语括号里的英文全称（SLA、SLO、MTTF、MTTR、MTBF、AFR、MPI、TP、TPC、DI、OLTP、SPEC 等改为「中文名（缩写）」；transient、permanent、response time、execution time、throughput、CPU time、workload、failure、restoration 等常见词的括注英文删去）；EEMBC、FIT、mercurial、silent data error、wall-clock time、benchmarketing 等不常见词保留英文。
