## 疑似原书错误或需核对（译文照原文）

- 图 2.1 (A) PMD 的 L1 容量标为「0 KB」，疑为笔误（应是几十 KB）；图内文字未改，图注不涉及。
- 图 2.2 图注「see Figure 2.4 on page 88」：本章从书页 94 开始，第 88 页不在本章，疑沿用旧版页码。译文照写「第 88 页的图 2.4」并加了 `#fig-2-4` 链接，合并时统一处理页码。
- 「Figure B.8 on page 24」「Appendix B, page B.36」同为原书页码，照写「附录 B 第 24 页的图 B.8」「附录 B 的 B.36 页」。
- i9 带宽：4 次 × 8 核 × 3 GHz = 960 亿次，原文写 192 billion（1920 亿），相当于每核每周期 8 次；(1920 + 480) 亿 × 16 B = 3840 GB/s，与总带宽一致。照原文译，前后数字疑有一处不一致。
- 「only 2% of the demand bandwidth (56 GiB/s)」：56/3840 ≈ 1.5%，照原文译 2%。
- 「the Arm Cortex-53」：通常写作 Cortex-A53，照原文写 Cortex-53。
- 「The Intel Core i7, among many others」：本版其他地方都用 i9，照原文写 i7。
- 功耗预算「20 to 50 times smaller」译「只有高端处理器的 1/20 到 1/50」，补出了比较对象「高端处理器」（原文承接上句的 high-end microprocessors）。

## 本节新定术语

- memory hierarchy 存储层次；inclusion property 包含性；secondary storage 二级存储。
- tag 标记（首次注英文）；set 组；block address 块地址。
- write merging 写合并（与 2.4–2.5 节一致）；nonmerging write-through 不合并的写直达。
- static / dynamic power 静态功耗 / 动态功耗；leakage 漏电。
- three C's model 3C 模型；coherency miss 一致性失效；misses per instruction 每条指令的失效次数；misses per 1000 instructions 每 1000 条指令的失效次数。
- LLC 最后一级 Cache（LLC），已在本节首次给出，供 2.4–2.5 节核对。
- read-after-write hazard through memory 经由存储器的写后读冒险。
- page offset 页内偏移量；virtual index / physical tag 虚拟索引、物理标记。
- TLB 首次出现写「TLB（translation lookaside buffer）」，与 2.4–2.5 节写法略有不同，全章需统一。
- HBM 高带宽存储器（HBM），首次出现在图 2.2 图注。
- multichip socket 多芯片插座；memory channel 存储通道；multiporting 多端口。
- SSD 固态盘；HDD 硬盘驱动器；archival storage 归档存储。
- speculative processor 推测执行的处理器；latency-tolerating techniques 容忍延迟的技术；outstanding miss 尚未完成的失效。
- 六种基本优化的段首斜体小标题照第 1 章写法，用「*……*：」。
