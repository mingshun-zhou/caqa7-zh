# 第 2 章校对记录：2.2 节（PDF 第 9–19 页）

## 疑似原书错误（译文照原文）

- 第 10 页 “the L3 access time is usually at least five times faster than a DRAM access”：“five times faster” 按倍数规则译成「DRAM 的访问时间通常仍至少是 L3 的 5 倍」。
- 第 12 页 “a fourfold improvement in capacity every 3 years, or 55% per year”：每 3 年 4 倍相当于每年约 59%，原书写 55%，照原文。
- 第 13 页 “From DDR1 to DDR3, access times improved by a factor of about 3, or about 7% per year”：按图 2.4，42 ns→26 ns 约 1.6 倍，63→39 也约 1.6 倍，与「约 3 倍」对不上；照原文译「缩短为原来的大约 1/3」。
- 第 13 页 “the next doubling happened at the end of 2024!”：原书带感叹号，译文改用陈述语气「直到 2024 年底才出现」，意思不变。
- 图 2.4 图注 “in 2024, it has four times the density per chip”：没有说跟谁比，按上下文理解为跟 DDR4 比，译「是 DDR4 的 4 倍」。表中 2021 年 DDR5 仍写 8G bit，跟图注不冲突。
- 图 2.5 最后一行 DRAM 名称原书印作 “DD5-4800”，应为 DDR5-4800；表格照原样保留 DD5-4800，需要统一处理时再改。
- 图 2.5 中 DDR2-533 的 DIMM 带宽 4264 对应 PC4300，原书就是这么写的（业界惯例取整），照原文。
- 第 17 页 Flash 第 1 条：pdftotext 把 µs 抽成 “mS”，页面图上是 µS（25 µS、75 µS），译文写 25 μs、75 μs。按 25 µs + 2 KiB / 40 MiB/s ≈ 75 µs 核对无误。「DDR SDRAM 不到 450 ns」按 40 ns + 2 KiB / 5 GiB/s ≈ 440 ns，也相符。
- 第 17 页 “write leveling”：业界通行说法是 wear leveling（磨损均衡），原书两处都写 write leveling。照原文译「写均衡」并附英文，建议全章统一时再定。
- 第 17 页 “Flash is about 1500 times slower than SDRAM”：译「只有 SDRAM 的约 1/1500」。
- 第 18 页 “thus the alternative name memristor”：严格说忆阻器和 PCM 是两类器件，原书说法不严谨，照原文译。
- 第 18 页 “Xpoint”：通常写作 3D XPoint，照原文写 Xpoint。
- 第 19 页 “For parity, even a server with only one processor …… higher than a 10,000-server Chipkill-protected system”：前文说的是 10,000 个处理器的服务器，这里写成 10,000-server，照原文。
- 图 2.7 图注 “AMD Genoa chip set”：带 3D V-Cache 的型号一般称 Genoa-X，照原文写 Genoa。
- 第 9 页 “which requires a high bandwidth memory (HBM)”：这里的 HBM 是泛指「高带宽的存储器」，和后面「封装创新」小节专指的 HBM 技术不同，原书在这里就用了缩写。译「这就要求存储器有很高的带宽（HBM）」，括号照原文保留。

## 本节新定术语

- memory technology 存储技术；memory hierarchy 存储层次
- SRAM 静态随机访问存储器；DRAM 动态随机访问存储器；nonvolatile 非易失性
- rank 保留英文 rank（与「存储体（bank）」并列，首次出现）
- access time 访问时间；burst transfer / burst mode 突发传输 / 突发模式
- row access strobe (RAS) 行访问选通；column access strobe (CAS) 列访问选通
- precharge 预充电；Activate（Act）激活；sense amplifier 读出放大器；sensing wires 读出线
- synchronous DRAM (SDRAM) 同步 DRAM；double data rate (DDR) 双倍数据率
- dual inline memory module (DIMM) 双列直插存储模块
- power-down mode 掉电模式；low-power DDR (LPDDR) 低功耗 DDR；GDRAM 图形数据 RAM
- off-chip 片外；LLC 末级 Cache（LLC）——本节首次出现，若前面 2.1 节已定义，可去掉括号
- stacked die 堆叠晶片；die stacking 晶片堆叠；interposer 中介层（首次注英文）；stack 堆栈
- vertical stacking (3D) 垂直堆叠；interposer stacking (2.5D) 中介层堆叠（图内标注未译）
- high bandwidth memory (HBM) 高带宽存储器（与 1.6 节图 1.15 一致）
- embedded DRAM 嵌入式 DRAM
- EEPROM 电可擦除可编程只读存储器；secondary storage 二级存储；solid-state disk 固态盘
- write leveling 写均衡（见上，待定）
- phase-change memory (PCM) 相变存储器；memristor 忆阻器；crystalline / amorphous 晶态 / 非晶态
- hard error / permanent fault 硬错误 / 永久性故障；soft error / transient fault 软错误 / 瞬时故障
- spare row 备用行；parity 奇偶校验；error correcting code (ECC) 纠错码（ECC）
- silent data error 静默数据错误（第 1 章 silent data corruption 译「静默数据损坏」，两者原文不同，分别照译）
- unrecoverable error 不可恢复错误；Chipkill、SDDC、RAID 保留英文
- Micron 美光（图 2.6 图注首次注英文）
