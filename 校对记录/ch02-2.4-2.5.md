## 本节新定术语

- side-channel attack 旁路攻击（另有「侧信道攻击」的译法，全章需统一）。
- prime / probe 填充 / 探测；prime-probe sequence / attack 填充—探测序列 / 攻击。首次出现注英文。
- spy / victim 窥探者 / 受害者。
- mitigation 缓解措施；leakage rate 泄露率；obfuscate timing 混淆时间；partition resources 划分资源；cache partitioning Cache 划分。
- LLC 直接用缩写（应在 2.1–2.3 节已给出「最后一级 Cache（LLC）」，需核对）。
- user / supervisor (kernel) mode 用户模式 / 管理模式（内核）；supervisor process 管理进程；system call 系统调用；process switch / context switch 进程切换 / 上下文切换；multiprogramming 多道程序设计。
- page table entry (PTE) 页表项（PTE）；use bit / dirty bit 使用位 / 脏位；protection field 保护字段。
- translation lookaside buffer 保留英文原词，写作「translation lookaside buffer，即 TLB」（未用「快表」）。
- enclave 保留英文（第 6 章定译名后统一）。
- physically / virtually addressed cache 物理地址 Cache / 虚拟地址 Cache。
- Autonomous Instruction Fetch Units 自主取指部件；instruction fetch unit 取指部件；microoperation 微操作；speculation 推测执行；speculative exception 推测异常。
- stale data 过时数据；I/O cache coherency I/O Cache 一致性；write merging 写合并；memory-mapped I/O 存储器映射 I/O；noncacheable 不可缓存。
- shadow page table 影子页表。
- Cross-Cutting Issues 交叉问题（节标题，需和其他章统一）。
