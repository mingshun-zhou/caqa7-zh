## 疑似原书错误（译文照原文，除特别说明外）

- 第 50 页 “The memory hierarchy of the Cortex-A8 was measured”：本节讲的是 A53，A8 应是上一版遗留。照原文译「Cortex-A8」。
- 第 50 页：D-Cache 32 KiB、页 4 KiB 时说 “cache index is 7 bits and the block offset is 6”，7+6=13 位比 12 位页内偏移多一位，对应 32 KiB 四路（与图 2.19 图注一致）；但图 2.18 表中 L1 数据 Cache 写的是 2 路组相联。照原文。
- 第 50 页正文说图 2.19 “16 KiB page size”，图 2.19 图注说 “using a 64 KiB page”，图中页内偏移为 16 位（即 64 KiB）。两处照原文。图 2.19 中 L1 I-Cache 索引 10 位，与 32 KiB 两路 64 字节块（应为 8 位）也对不上，图未改。
- 第 51 页 “the L2 penalty is 9.5 times as high”，而图 2.21 图注说 “more than five times higher”；按图 2.18，124/13≈9.5。两处照原文。另「L1 失效率约为 L2 的 7 倍」与前文中位数 2.4% / 0.3%=8 大体相符。
- 第 53 页 “36-bit physical addresses, yielding a maximum physical memory of 36 GiB”：2^36 B = 64 GiB。照原文「36 GiB」。
- 第 54 页图 2.22 表头 “Data DLB”，应为 Data TLB，译「数据 TLB」。
- 第 55 页图 2.23 表头最后一列印作 “L2”，按内容（30 MiB 共享、非包含、15 路、50 周期）应为 L3，**译文已改为 L3**，请确认。
- 第 57 页 “The four tags and valid bits are compared”：指令 Cache 是 8 路，应为 8 个标记。照原文「这 4 个标记」。
- 第 57 页 “Therefore 6 + 1 or 87 bits”：显然应为 7 位。照原文「6 + 1 即 87 位」，建议统稿时改为 7。
- 第 57 页 L2：正文说 30 位块地址分为 19 位标记和 11 位索引，图 2.24 中 L2 为 Tag <20>、Index <10>、存储的 Tag <21>（旧版 i7 数据）。照原文，图未改。
- 第 58 页 L3：正文算出标记 18 位，图 2.24 中 L3 为 <17> Tag、<13> Index。照原文。
- 第 59 页 “MKPI2 and MKPI3”：应为 MPKI2、MPKI3，**译文已改为 MPKI**。
- 第 59 页 “in the section on hardware prefetching starting on page 23”：硬件预取在 2.3 节「第八种优化：指令和数据的硬件预取」，页码 23 疑为占位或 PDF 内页序。照原文「第 23 页」，统稿时可改成 [2.3 节](#sec-2-3) 的链接。
- 第 59 页 “four of the benchmarks have significant L1D misses exceeding 20 instructions per thousand”：意思是每千条指令超过 20 次失效，按意思译。
- 第 59 页 “Recall that a number of the floating-point SPEC benchmarks also have high cache miss rates, as we discussed earlier when examining prefetching on the i7”：前文实际讨论的是 Skylake/Xeon 上的预取（图 2.15），照原文「i7」。
- 第 53 页 “big.little”：ARM 官方写法为 big.LITTLE，照原文斜体小写。

## 本节新定术语（请全章统一）

- virtually indexed, physically tagged 虚拟索引、物理标记；physically indexed 物理索引；virtually addressed 虚拟寻址
- critical word first 关键字（最先返回）
- alias / aliasing 别名；page coloring 页着色
- page frame 页帧号（“page frame of the address”）；page offset 页内偏移；block offset 块内偏移；index 索引；tag 标记；valid bit 有效位；protection bit 保护位
- micro-TLB 微 TLB；unified TLB/cache 统一 TLB / 统一 Cache；STLB 保留
- page map cache 页映射 Cache（首次注英文）；page structure cache 页结构 Cache（首次注英文）
- page table walker 页表遍历器（首次注英文）；walk the page table 遍历页表；page fault 缺页；secondary storage 外存
- allocate on write / write-allocated 写分配；merging write buffer 合并写缓冲；write merging 写合并
- inclusive / noninclusive 包含式 / 非包含（的）；LLC 末级 Cache（LLC）
- dirty cache line 脏 Cache 行；eject from L2 从 L2 逐出
- global / local miss rate 全局失效率 / 局部失效率；stand-alone miss rate 「单独计算的失效率」
- cache buster 「Cache 杀手」
- demand access / demand miss 按需访问 / 按需失效；prefetch access 预取访问；prefetcher 预取器
- MPKI 每千条指令的失效次数（MPKI）
- instruction graduation 指令毕业；commit 提交；load-store queue 保留英文 load-store 队列
- IP core 知识产权（IP）核；hard core / soft core 硬核 / 软核
- P-core / E-core 性能核（P-core）/ 能效核（E-core）
- memory channel 内存通道；DIMM、HBM 保留
- Pseudo-LRU 伪 LRU；approximate LRU 近似 LRU；NRU 保留；Weighted n-bit LRU 加权 n 位 LRU
- associativity 相联度；dual ported 双端口；outstanding writes 未完成的写
