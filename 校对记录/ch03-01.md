## 新定术语

- dependence：相关（data dependence 数据相关、true data dependence 真数据相关、name dependence 名相关、antidependence 反相关、output dependence 输出相关、control dependence 控制相关）；independent 无关。不用「依赖」作术语，但普通叙述中 depend on 可译「依赖」。
- name：名；program order：程序顺序；dependence chain：相关链。
- RAW / WAW / WAR / RAR：写后读 / 写后写 / 读后写 / 读后读，保留缩写。
- basic block：基本块；loop-level parallelism：循环级并行；loop unrolling：循环展开。
- forwarding and bypassing：前递和旁路；pipeline interlock：流水线互锁。
- dynamic memory disambiguation：动态存储器消歧。
- software pipelining：软件流水；trace scheduling：踪迹调度（与第 1 章「基于踪迹的编译」一致）；deep pipelining：深度流水。
- simultaneous multithreading：同时多线程（SMT）。
- static issue pipeline：静态发射流水线。
- exception behavior：异常行为；data flow：数据流；memory protection exception：存储保护异常。
- branch is taken：转移成功。
- IPC：每个时钟周期执行的指令数。
- 统稿补译：第 10 页（书页 184）原稿漏译，从「正确的做法是，指令执行时必须保持数据流」到本节末尾，由统稿补上。
