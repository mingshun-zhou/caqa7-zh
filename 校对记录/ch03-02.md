## 疑似原书错误（译文均照原文）

- 第 12 页例题：「taking nine cycles per array element」，但下面列出的发射周期只到 8；第 14 页正文也说展开前「8 cycles per element」。照原文译「9 个周期」。
- 第 13 页展开 4 次的例题：题目要求「do not reuse any of the registers」，但第 3 个元素的代码仍用 f0（fld f0,-16(x1) / fadd.d f12,f0,f2）；第 14 页调度后的代码改用 f10。代码照原文。
- 第 14 页调度后的代码：addi x1,x1,-32 在 4 条 fsd 之后，后两条 fsd 的偏移却写成 16(x1)、8(x1)（像是 addi 提前后的补偿值），按前后文应为 -16(x1)、-24(x1)。代码照原文。
- 第 19 页「it uses a different set of integer registers for each iteration」：展开时换的是浮点寄存器（f0/f4、f6/f8…），integer 疑为 floating-point 之误。照原文译「整数寄存器」。
- 第 19 页「our example code uses only registers f0, f2, f4, and f6」：示例循环只用了 f0、f2、f4，没有 f6。照原文。
- 第 19 页 (0.95)^39 = 13.5%：数值无误（0.95^39 ≈ 0.135）；200 条指令 / 5 条每次迭代 = 40 条转移，取 39 是最后一条之前全部预测正确。照原文。
- 第 18 页「a predicted branched execute」、第 19 页「preceeding」、第 23 页「multiple load/store instruction」：笔误或语法错，按正确意思译。
- 第 17 页「can overlap the execution 60 instructions」缺 of，按意思译。
- 第 16 页说硬件机制的窗口是「tens to a few hundreds of instructions」，第 20 页说跟踪操作数的结构容量「a few tens to a hundred instructions」，两处数字范围不同，各自照译。
- 第 17 页 CPU 时间公式原文为 CPU time = IC · CPI · CCT，CCT 未展开（时钟周期时间），照原文写缩写。
- 第 18 页小标题与正文：原书用箭头「Control dependences → Branch prediction and speculative execution」等，标题保留箭头。

## 本节新定术语（请全章统一）

- data / name / control dependence：数据相关 / 名相关 / 控制相关（与第 1、2 章已有用法一致）；antidependence 反相关；output dependence 输出相关；WAW、WAR 保留缩写
- static issue / static scheduling：静态发射 / 静态调度；dynamic scheduling 动态调度
- loop unrolling 循环展开；loop overhead 循环开销；loop termination code 循环的结束代码
- symbolic substitution and simplification 符号替换和化简
- strip mining 分段开采（首次注英文）
- register pressure 寄存器压力；live / live values 存活 / 存活的值
- straight-line code 直线代码
- fully pipelined 全流水的；structural hazard 结构冒险；functional unit 功能部件
- superscalar 超标量；out-of-order (OOO) 乱序（OOO）；in-order 顺序；OOO 在正文中保留缩写
- redundant code elimination 冗余代码消除；strength reduction 强度削弱；register allocation 寄存器分配
- deeper pipelining 更深的流水线；multiple / wide issue 多发射 / 宽发射；4 instructions wide 宽 4 条指令 / 4 路发射
- direction prediction / target prediction 方向预测 / 目标预测；dynamic branch prediction 动态转移预测
- taken（转移）成功（与第 2 章一致）；resolve the branch 解析转移；in flight 在途
- recovery mechanism 恢复机制；mispeculation 错误推测；misprediction 预测错误
- physical register / architectural register 物理寄存器 / 体系结构寄存器
- data-flow order 数据流顺序；ready for execution 可以执行；instruction age / criticality 指令的年龄 / 关键程度
- speculative memory disambiguation 推测式存储器消歧；memory dependence 存储相关；address generation unit 地址生成部件；effective address 有效地址
- precise exceptions 精确异常；page fault 缺页；arithmetic overflow 算术溢出
- ROB entry ROB 表项；head of the ROB ROB 头部
- front-end / execution engine / back-end 前端 / 执行引擎 / 后端
- fetch / decode / issue / dispatch / complete / commit (retire)：取出（取指）/ 译码 / 发射 / 分派 / 执行完毕 / 提交（退休）。issue 与 dispatch 在本书中区分：issue 指送入动态调度结构，dispatch 指送往功能部件执行；dispatch 首次注英文
- instruction bundle 指令包（首次注英文）
- scheduling entry 调度表项
