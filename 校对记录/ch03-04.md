## 本节新定术语

- tagged hybrid predictor 带 tag 的混合预测器；TAGE 保留英文。
- PPM（prediction by partial matching）部分匹配预测。
- aliasing 别名（首次注英文）；hashing collision 散列冲突。
- saturating counter 饱和计数器；tournament predictor 竞争预测器（若前文已另定，请统一）。
- use field 使用字段；hint bit 提示位；valid bit 有效位。
- mispredict / misprediction 误预测；misprediction rate 误预测率；mispredicts per thousand instructions 每千条指令误预测数。
- mispeculation 错误推测执行。
- loop exit predictor 循环退出预测器；loop branch predictor 循环转移预测器。
- branch-target buffer (BTB) 转移目标缓冲（BTB）；branch-target cache 转移目标 Cache。
- target instruction / target address 目标指令 / 目标地址；branch folding 转移折叠（首次注英文）。
- indirect jump 间接跳转；procedure return 过程返回；FORTRAN-computed goto 计算 goto。
- return address stack (RAS) 返回地址栈（RAS）；return address buffer 返回地址缓冲；fix-up mechanism 修复机制。
- integrated instruction fetch unit 集成的取指部件；decoupled front-end 解耦前端（首次注英文）；fetch bundle 取指包。
- five-component 五分量。
