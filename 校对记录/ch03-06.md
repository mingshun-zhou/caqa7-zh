## 本节新定术语（请全章统一）

- dependence 相关；data dependence 数据相关；name dependence 名相关；register dependence 寄存器相关；memory dependence 存储相关
- memory disambiguation 存储消歧；speculative memory disambiguation 推测式存储消歧（首次注英文）；speculative but selective memory disambiguation 推测式选择性存储消歧
- load bypassing load 旁路（首次注英文）
- store forwarding store 前递（首次注英文）
- store buffer store 缓冲；load-store queue load-store 队列；load/store queue entry load/store 队列表项

- mispeculation 误推测；mispeculated instructions 误推测执行的指令
- value prediction 值预测
- spill / restore 溢出 / 恢复
- architectural register 体系结构寄存器
