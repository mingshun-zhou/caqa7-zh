## 疑似原书错误、存疑（译文都照原文）

- 第 101 页代码注释 `fsub.d f2,f2,f4 # temp = guess – temp`：这条指令写的是 f2，即 guess，注释应为 guess = guess – temp。照原文保留。
- 第 101 页「finding the root of equation x² − s」：严格说应是方程 x² − s = 0。照原文译。
- 第 102 页 3.1 的「To solve this problem, fill in a table like the one below」排在表的下方，是排版问题。译文把这句移到表前。
- 3.1 写「dependent instructions can issue」、3.2 和 3.4 写 issue、3.5 和 3.6 写 dispatch、3.3 同时出现「issue and commit out of order」和「dispatch per cycle」。原书 issue 和 dispatch 混用，译文照原文分别译「发射」和「分派」。
- 第 104 页 3.12 的「None of the BEQAL branches is taken」：代码里只有 beq，没有 BEQAL，应指 beq。照原文保留 BEQAL。
- 3.12 代码是 RISC-V 风格，但用了 `daddiu`（MIPS 指令）和 `#64` 立即数写法；lw 的偏移按 8 字节递增。照原文。
- 3.13 正文说「R1 置为数组 X 的基地址，R2 置为 Y 的基地址」，代码里用的是 x1、x2；首行注释「x1 = upper bound for X」应为 x4。照原文。
- 3.13 代码里浮点寄存器大写（F2、F0 等），和 3.1 的小写不一致。照原文。
- 3.13(c)「schedule it without any stalls (i.e., completely empty issue cycles)」：括号里应是解释「停顿」指什么，即完全空闲的发射周期。照译。
- 3.13(c)「What percent of the operation slots are used」译「操作槽的使用率是多少」。
- 3.18 小题分值写 [10/5]，而 (b) 标的是 [10]：这是 3.18 的事，不在本文件范围，提供给下一文件参考。
- 第 107 页局部预测器表第 3 行「Last 2 outcomes」只写了一个 NT，按理应为 NT,NT；但第 7 行已经是 NT,NT，这样表项 0–3 没有 NT,NT 这种组合。照原文写 NT。
- 第 107 页相关预测器表的第 2 列（Branch）是转移的编号 0–3，而转移结果表里给的是 PC 地址（454、543、777），只有 3 条转移。照原文。
- 3.16「T with one misprediction」译「T，已有一次预测错误」，指 2 位饱和计数器当前预测为 T，但已经错过一次（弱状态）。

## 新定术语（与第 3 章已有校对记录对齐）

- dispatch 分派（同 ch03-06）；resolve（转移）确定结果。
- forwarding bus 前递总线；live / live cycles 活跃 / 活跃周期；register lifetime 寄存器生存期。
- dual issue / dual commit 双发射 / 双提交；issue slot 发射槽；operation slot 操作槽。
- multithreading (MT) 多线程（MT）；simultaneous MT 同时多线程；fine-grained MT 细粒度多线程；coarse-grained MT 粗粒度多线程；round-robin 轮转。3.11 节如另有定法，请统一。
- barrier 屏障；list searcher 列表搜索程序。
- DAXPY 保留英文；Gaussian elimination 高斯消去法。
- delayed branch 延迟转移；branch delay slot 转移延迟槽；fully bypassed 完全旁路。
- FP ALU op 浮点 ALU 操作；load/store buffer slot load/store 缓冲槽；FPU 浮点部件（FPU）。
- structural hazard 结构冒险；broadcast 广播。
- correlating predictor 相关预测器；(m,n) correlating branch predictor (m,n) 相关转移预测器；two-level local predictor 两级局部预测器（同 ch03-03）。
- misprediction rate：ch03-03 用「预测错误率」，ch03-04 用「误预测率」，两者不一致。本文件用「预测错误率」，请统稿时统一。
- word address 字地址。
