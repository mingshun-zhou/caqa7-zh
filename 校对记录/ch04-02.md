## 疑似原书错误（译文均照原文）

- 第 16 页：「If the number of iterations of the loop is larger than n, then ... setvl sets vl to VLMAX」——按逻辑应为「larger than VLMAX」（即 n 大于 VLMAX）。照原文译「大于 `n`」。
- 第 16 页：「so setvl sets VLMAX to n」——应为 sets vl to n，VLMAX 不会被改写。照原文。
- 第 16 页：「it should compute only on the last n elements」——此处 n 指剩余元素数，照原文。
- 第 16 页 DAXPY 代码：首行写 vsetvl a3,a0,...，循环内 vsetvl t0,a0；正文说的是 setvl。照原文。
- 第 17 页：「the least-significant bit (bit 63)」——最低有效位应为第 0 位，代码注释也写 v0<63>(i)。照原文译「最低有效位（第 63 位）」。
- 第 17 页：「In RV64V predicate registers hold the mask ... Rather than have separate mask registers, RVV uses vector register v0」——前后对掩码存放的说法略有出入，照原文。
- 第 20 页存储体冲突条件公式：「存储体数 / 最小公倍数(步长, 存储体数) < 存储体忙时间」。代入步长 1、8 个存储体得 1 < 6，会判为冲突，与随后例题「步长 1 无冲突」矛盾；前几版原书此式为 LCM(步长, 存储体数)/步长 < 存储体忙时间。公式照原文。
- 第 20 页例题：76/64 ≈ 1.19，391/64 ≈ 6.11，391/76 ≈ 5.1，与「1.2」「6.1」「a factor of 5」相符。「slowing it down by a factor of 5」按手册倍数写法译「速度降为原来的 1/5」。
- 第 21 页 gather 代码：M[] 装入 v16，但下一条 vloxe64 用 (v2) 作索引，应为 (v16)。代码照原文。
- 第 21 页 gather 代码：vadd 是整数加，A、C 若为浮点应为 vfadd；照原文。
- 第 19 页例题数字已核：32×6=192；15/2.167=6.92→7；192×7=1344。

## 本节新定术语（请全章统一）

- maximum vector length (mvl) 最大向量长度（mvl）；vector-length register (vl) 向量长度寄存器（`vl`）
- strip mining 分段开采（strip mining）（与 03-ilp-02 一致）；fixup code 修正代码；loop bookkeeping 循环记账
- mask register 掩码寄存器；vector-mask control 向量掩码控制；predicate register 谓词寄存器
- conditionally executed instruction 条件执行指令；IF-conversion IF 转换（IF-conversion）；straight-line code 直线代码
- vector mode 向量模式；level of vectorization 向量化程度；vectorizing compiler 向量化编译器
- memory bank 存储体（bank）；memory interleaving 存储交叉；interleaving 交叉访问；bank busy time 存储体忙时间；memory bank conflict 存储体冲突
- start-up time 启动时间；initiation rate 发起速率
- row-major / column-major order 行主序 / 列主序（与第 2 章一致）
- stride 步长；unit stride / nonunit stride 单位步长 / 非单位步长；vlse / vsse 带步长的向量 load / store
- gather-scatter 集中—分散；gather / scatter 集中 / 分散；index vector 索引向量；indexed load/store 带索引的 load/store
- compressed / normal representation 压缩表示 / 普通表示；dense vector 稠密向量
- programmer directive 编译指示（程序员给出）
- true data dependence 真数据相关
- laissez-faire attitude 放任态度
