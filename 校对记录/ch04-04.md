## 疑似原书错误或存疑（译文均照原文）

- 图 4.13 图注「Four groups cluster these 11 terms」：表中实际有 13 个术语（程序抽象 3、机器对象 2、处理硬件 4、存储硬件 4）。照原文译「11 个」。
- 图 4.13 图注「We use the first column for hardware terms」：表的第一列是「类型」，描述性名称在第二列；正文也说「the left column」。照原文译「第一列」。
- 图 4.13 图注「Figure 4.21 on page 312 … Figure 4.24 on page 317 and Figure 4.25 on page 318」：本图在书页 323，这几张图在本节之后，页码 312/317/318 疑为沿用旧版页码。照原文保留，统稿时可删去页码。
- 第 41 页「a SIMD Processor has between an impressive 32,768–65,536 32-bit registers (1024 per lane in Figure 4.15)」：图 4.15 是 16 个车道 × 1024 = 16,384 个，与 32,768～65,536 对不上（Pascal 实际每 SM 64K 个，分属 2 个处理块）。照原文。
- 第 36 页「Subsequent NVIDIA GPUs have the same underlying microarchitecture, although generally copies of some of Pascal's features」：后半句语法不完整，按「一般会复制 Pascal 的某些特性」理解。
- 第 38 页图 4.14 图注「the hardware Thread Scheduler」：图注里的 Thread Scheduler 即正文的 SIMD Thread Scheduler，照原文译「硬件线程调度器」。
- 第 38 页图 4.14 图注「Thread Blocks (SIMD basic blocks)」：与正文「bodies of vectorized loop」说法不同，照原文译「SIMD 基本块」。
- 第 36 页「there is no "missing link" that explains both」：照译。
- 第 33 页引文作者「Vincent Natol」：一般写作 Vincent Natoli，照原文。
- 第 33 页「Appendix C in the 6th edition of Computer Organization and Design」：照原文；书名译《计算机组成与设计》并附英文。
- 第 35 页「specifying the grid dimensions and the number of threads per SIMD Processor」：严格说应是每个线程块的线程数，照原文。
- 第 34 页 CUDA 代码「__host__int nblocks」：__host__ 与 int 之间无空格，照原文（代码不动）。
- 第 40 页图 4.16 图注「memory-bus width of 4096 data wires」：照译「4096 根数据线」。
