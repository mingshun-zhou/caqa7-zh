## 疑似原书错误（译文的处理）

- 第 72 页正文：H100 睿频「2.0 GHz」、峰值带宽「3330 GB/s」；图 4.29 表中为 1.98 GHz、3350 GB/s。正文、表格均照原文，未统一。
- 第 74 页图 4.31 图注：「to 78 DP GFLOP/s and 512 DP GFLOP/s on the GTX 280」——512 应为单精度（SP），据图中运算强度 4 处 GTX 280 单精度线约 512 GFLOP/s。译文改为「512 SP GFLOP/s」。
- 第 75 页：「The GPU has 4.4 the memory bandwidth」等处倍数符号 × 在 pdftotext 中丢失，已按页面图核对，各倍数均照译。
- 第 75 页：「raw performance specifications of the GTX 280 vary from 2.5 slower (clock rate)」——图 4.30 时钟比为 0.41（约 1/2.4），照原文写「1/2.5」。
- 第 76 页：「If the index trees are small … the Core i7 is twice as fast」——图 4.33 Search 比值为 1.8（GTX 更快），这里是指小索引树的情形，与总体结果并不矛盾，照译。
- 第 78 页：「Thus Hist is only 1.7 faster than the GTX 280」——主语颠倒，按图 4.33（GTX 280/i7 = 1.7）应为 GTX 280 比 Core i7 快到 1.7 倍。译文按表改为「GTX 280 运行 Hist 的速度只是 Core i7 的 1.7 倍」。
- 第 78 页：「Intel's ACV2 added gather instructions」——ACV2 应为 AVX2，译文写 AVX2。
- 第 78 页：「The newer GPU chip is 15 to 50 times faster, the newer CPU chips are 50 times faster than their predecessors」——依据不明（按图 4.34 与图 4.30 的峰值 FLOPS 推算，GPU 单精度约 11～34 倍、双精度约 68 倍，CPU 约 44 倍），可能另有口径，照原文。
- 第 80 页图 4.36 图例：右图「Pascal DP」为虚线、「Pascal SP」为实线，与其他各条（SP 虚线在上）相反，疑为图例标反；图未改。
- 第 80–81 页：「different generation architecture radically changed the hardware instruction set」——主语未点明，按上下文补为「NVIDIA 在不同代的体系结构中」。
- 第 79 页：「NVIDIA now worth >30 as much as Intel」等倍数符号丢失，已按页面图核对为 >10×、>30×。
- 第 82 页「improved the performance by nearly a factor of two!」原为感叹号，按语体改为句号，译为「提高到原来的近 2 倍」。第 81 页「vectors had to be longer than 100 …!」同样改为句号。

- ridge point 脊点（与 04-dlp-03 一致）
- compute bound / BW bound 受计算限制 / 受带宽限制

- fetch-and-increment 取数加一
- barrier synchronization 屏障同步

- break-even point 盈亏平衡点；crossover point 交叉点
- start-up overhead 启动开销；memory-memory vector processor 存储器—存储器型向量处理器
- harmonic mean 调和平均
- killer app 杀手级应用
- coprocessor 协处理器；system processor 系统处理器（与 04-dlp-04 一致）
