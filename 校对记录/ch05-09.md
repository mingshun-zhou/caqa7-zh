## 新定术语

- ring / grid / hypercube：环 / 网格 / 超立方体
- hop：跳数
- clean exclusive state：干净的独占状态；owned state：「拥有」（owned）状态（与 05-tlp-02 的「拥有（Owned）状态」一致）
- race condition：竞争条件
- replacement hint：替换提示
- fully populated bit vector：全位向量；bit vectors that are not dense：非稠密的位向量
- "empty" directory：「空」目录
- compare-and-swap：compare-and-swap（比较并交换），load linked/store conditional 保留英文
- pad synchronization variables：对同步变量进行填充
- snoopy write invalidate protocol：监听式写作废协议（invalidate 沿用 05-tlp-04、05 的「作废」；05-tlp-02 用「使无效」，统稿时请统一）
- uncached memory operation：不经 Cache 的存储器操作；monitor unit：监视单元
- analytical model / trace-driven simulation / execution-driven simulation：解析模型 / 踪迹驱动模拟 / 执行驱动模拟；trace：踪迹
- spin-wait synchronization：自旋等待同步
- biased benchmark：「有偏」基准测试程序；inverse linear speedup：反线性加速比
- cluster：机群
